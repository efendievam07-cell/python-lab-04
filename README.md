# Лабораторная работа № 4
## Работа со списками и кортежами в языке Python

### Окружение
* **Язык программирования:** Python 3.14
* **Среда разработки:** Visual Studio Code
* **Виртуальное окружение:** `.venv`

### Назначенные индивидуальные варианты
* **Задание 1:** Вариант 4 (Сумма отрицательных элементов списка из 10 целых чисел)
* **Задание 2:** Вариант 1 (Сумма отрицательных, произведение между первым максимумом и первым минимумом, сортировка по возрастанию)
* **Задание 3:** Вариант 25 (Кортеж: удвоение четных значений и сохранение нечетных)

### Список программ
1. `selected_sum.py` — сумма элементов по условию (пример 1)
2. `between_extrema.py` — количество элементов между экстремумами (пример 2)
3. `filter_sort.py` — фильтрация и сортировка копии списка (пример 3)
4. `sensor_readings.py` — обработка списка записей-кортежей (пример 4)
5. `individual_01.py` — индивидуальное задание 1 (Вариант 4)
6. `individual_02.py` — индивидуальное задание 2 (Вариант 1)
7. `individual_03.py` — индивидуальное задание 3 (Вариант 25)
